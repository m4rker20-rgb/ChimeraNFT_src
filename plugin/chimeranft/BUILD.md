# Сборка плагина из восстановленных исходников

Эта папка (`chimeranft/`) — реконструкция плагина Chimera NFT для Exteragram,
собранная из восстановленных исходников. Файловая защита (контейнер
`CHIMERA_CONTAINER_V3`, вшитый в `libtdcompat.so`) **снята**.

## Что внутри
- `src/loader.py` — загрузчик плагина.
- `native/arm64-v8a/libtdcompat.so`, `native/armeabi-v7a/libtdcompat.so` —
  нативная библиотека (её нативный код также выполняет анти-тампер/ban-логику
  во время работы, поэтому бинарь оставлен как есть; его декомпилированный
  C-код — в `../../src/native/`).
- `res/`, `locales/`, `meta.yml`, `refmap.yml` — ресурсы и метаданные плагина.
- `chimeranft_core.dex` — **расшифрованное ядро** (`com.chimeranft.core.Main`),
  которое в оригинале было спрятано зашифрованным внутри `libtdcompat.so`.
  Положено отдельным asset'ом, чтобы грузиться напрямую, минуя зашифрованный
  контейнер.

## Как собрать/запустить без файловой защиты
Ядро теперь лежит в открытом виде (`chimeranft_core.dex`). Чтобы не использовать
зашифрованный контейнер, загрузчик должен открывать `chimeranft_core.dex`
напрямую (через `DexClassLoader`/аналог), а не через `nativeOpenCore` из
`libtdcompat.so`. Вся логика плагина (включая анти-фрод/ban/guard) сохранена
без изменений.

Исходный код ядра: `../../src/core/smali/` (smali) и
`../../src/core/chimeranft_core.dex`. Python-рантайм: `../../src/python/`.
